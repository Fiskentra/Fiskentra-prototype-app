# Fiskentra v0.22 — новый дизайн карты

## Исправление v0.22.1

В v0.22 новая карта обходила `SwipeSwitchLayout`, поэтому обратный свайп к прогнозу пропал. Обёртка восстановлена; в шапку добавлена кнопка Weather forecast. На карте переключение работает в обе стороны от бокового края или по шапке, на Forecast — горизонтальным свайпом. Перемещение внутри карты остаётся жестом карты; касания несколькими пальцами не переключают экран.

Сборка и Lint прошли. На телефоне прошли все 7 проверок `qa/Test-WeatherSwipe.ps1`: начальный экран, четыре перехода между Forecast/Map, сохранение карты при перетаскивании в центре и открытие прогноза кнопкой. Обновление установлено без сброса данных. APK: `build/distributions/Fiskentra-v0.22.1-weather-swipe.apk`.

Реализован на основе трёх **последних** мокапов Trip, Track и Navigation из [переписки с дизайном](https://chatgpt.com/share/6aa6fbb2-9284-83ed-84fc-8682c3e57f96). Исходники продолжают ветку `codex/field-map-v021` в этой папке; данные и функции v0.21 сохранены.

## Интерфейс

- Спутниковая карта, тёмно-синие панели, светлый текст и синие кнопки. При первом открытии после обновления выбран Satellite; следующий выбор пользователя сохраняется. Открытие скачанной области использует её выбранный стиль.
- Шапка Fiskentra с поиском сохранённых точек и вводом координат. Отдельная строка Flic / GPS, отметка Offline при потере интернета, подробности соединений по значку GPS. Ошибки загрузки карты видны поверх карты.
- Справа: слои, офлайн-карты, местоположение. Слева снизу: Trip / Track / Navigation / Map only, история, GPX, прогноз.
- Trip: длительность, уловы, точки, список событий и начало/завершение поездки. Завершённая поездка явно обозначена Last trip / Saved.
- Track: расстояние и прошедшее время поездки, пауза/продолжение, остановка с сохранением. Прошедшее время включает паузы — это указано подписью Trip elapsed.
- Navigation: расстояние, истинный азимут, направление относительно телефона, круглый компас. Компас и верхняя подсказка появляются только при выбранной цели. Show point показывает цель, Stop завершает навигацию.
- Кнопка Point сохраняет все способы добавления: свежая GPS-позиция, центр карты, касание карты, координаты. Долгое нажатие остаётся доступным.
- Маркеры получили короткую ножку, белую обводку, встроенные значки и тёмные подписи. Близкие точки объединяются в круг с числом; нажатие открывает список всех точек группы. Координаты не сдвигаются. Пользовательские цвет, значок и относительный размер сохраняются.
- Нижняя навигация: Map / Journal / Saved / Devices. Прогноз доступен из меню карты.

## Границы

Навигация остаётся прямой. Дорожный маршрут, Walking/Driving, повороты, парковка, ETA, Steps и голосовые дорожные команды из навигационного мокапа требуют отдельного движка маршрутизации и не реализованы в этой версии. Числа и дорожные указания из макета не подставляются вместо реальных данных.

Физические обрывы Bluetooth/GPS, новая запись трека в движении и офлайн-перезапуск в авиарежиме в этой проверке не повторялись. Их поведение унаследовано от v0.21.

APK: `build/distributions/Fiskentra-v0.22-map-design.apk`.
