# Fiskentra — 10 product design directions

This folder contains a Designly-led exploration for the next Fiskentra product UI.

Open `fiskentra-10-concepts.html` in a browser. It is a self-contained, responsive comparison gallery with ten deliberately different UX directions. Every direction uses the same four control views — Today, Forecast, Map and Journal — so the concepts can be compared fairly.

## Product lock

Every concept includes the combined capability set of:

- Fiskentra prototype: live GPS, saved moments, trip tracks, typed markers, MapTiler map, Flic 2 actions, local-first storage, Supabase sync/delete recovery.
- Bite Forecast reference: 3-hour / 5-day weather, provider selection, barometer correction, bite score with explained factors, moon, geomagnetic activity, waves, species forecasts, calendar/statistics, news and offline reference library.
- Susanin reference: offline fishing/depth, historical, topographic and custom maps; layer opacity; point photos/audio/notes; sharing; voice guidance to a point; accuracy radius; routes/tracks; GPX import/export; manual coordinates; ruler; cloud backup and Wear OS controls.

The artifact is a design exploration, not production app code. The recommended route for implementation is concept 10's adaptive architecture with concept 1's field readability and concept 4's one-handed Flic capture.

## Files
